What happens after you press submit

The same request/response cycle covered in CO-1 — a browser-issued HTTP request, a server response, and a standards-compliant record of the data.

01

Client validation

Required fields are checked in the browser before anything is sent.

02

HTTP POST

Form data is sent to /api/complaints in the request body, not the URL.

03

Server processing

The server validates, assigns a tracking ID, and stores the record.

04

201 Created

On success the server replies with a Location header pointing to the new complaint resource.

05

XML record

The complaint is persisted as a well-formed, schema-valid XML entry for the registry.
